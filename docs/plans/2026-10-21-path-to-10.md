# IntentLock — path to 10 (2026-10-21)

Branch `harsha/path-to-10`. Local work only; nothing pushed, released or submitted.

## What it is for

IntentLock is a Manifest V3 Chrome extension for people who lose work time to drifting tabs
(students, developers, writers, job seekers). Every new tab asks what you are about to do and for an
optional time budget. While the session runs, the service worker checks each page load, tab switch,
SPA navigation and dwell report against local heuristics (an intent taxonomy plus a 529-domain site
taxonomy, strictness presets and custom allow/block rules). When you drift, exceed the budget, or
come back from idle into an unrelated tab, it covers the page with a full-screen lock that needs a
written reflection to continue, or Close tab / End session. An optional AI provider key (kept in
session storage only) adds a second opinion; it can never overrule explicit allows. All data stays
in `chrome.storage` on the device, with retention pruning and one-click deletion.
